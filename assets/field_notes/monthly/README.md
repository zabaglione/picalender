# Painted monthly backgrounds

Twelve text-free backgrounds generated with the built-in `image_gen` tool on
2026-10-01. All images belong to the same restrained gouache / washi-paper
collection. Month 01 was generated first; it served as the visual reference for
months 02–12. The complete final prompts are in `generation-prompts.json`.

These are production assets, loaded by `src/renderers/wafu_theme_design.py`.
They contain no live calendar, weather, clock or lunar data. Information surfaces
are composed by the renderer; the existing daily illustration is preserved in
its own rectangle. No external service is needed to display these backgrounds.

The old Japanese month names inform the illustrations. Some associations reflect
the old calendar and therefore differ from modern-calendar seasons. Actual
switching uses the configured timezone's modern calendar month.
