# PiCalendar 機能一覧

2026-10-01時点の `main.py` の起動経路に基づきます。

## 標準のField Notes画面

- 時計、日付、当月カレンダー、日曜／月曜始まり、日本の祝日、旧暦による六曜。
- 月齢、照明率、月の図形、英日併記の月相名、次の朔弦望。
- 設定地点の日の出・日の入・月の出・月の入、次の祝日。
- Open-Meteoの3日予報、取得日時、欠測と古い予報の区別、取得済みデータの保持。
- 12か月の手描き背景と配色の自動切替。背景PNGは同梱しオフラインで使用。
- 任意の日替わりイラスト。別サーバーへ記念日・季節・祝日・有効な予報を渡して生成し、Piは最新画像を保持。
- systemd起動、環境検出、FPS制御、SIGUSR1による稼働中描画面の保存。

## 旧画面と独立モジュール

`ui.style: classic` は旧時計・カレンダー・天気・月相・壁紙を表示します。フォントサイズや壁紙ローテーションの設定が使えます。標準画面とは対応設定が異なります。

キャラクター、アニメーション、OpenWeatherMap、高度な設定管理・性能管理には独立モジュールと過去のテストがありますが、現行 `main.py` に統合されていません。Yahooプロバイダは現在の起動経路にありません。ICS連携、Web設定画面、警報表示、輝度制御を実装済みとは扱いません。

旧5種類のYAMLプリセットは残っていますが、テーマ管理ツールは移動後のパスに対応していません。現行の月別背景とは別機能です。[テーマガイド](THEME_GUIDE.md)

## 確認範囲・制約

標準画面は1024×600基準の固定配置で、別寸法へ全体を拡縮します。任意解像度での実機確認、Pi 3／4、各OSでの性能数値や72時間の連続稼働を、現行版の確認済み事項として保証しません。

過去のPi Zero 2 Wでの計測と稼働画面の確認は[2026-09-18の記録](../redesign-validation-2026-09-18.md)、その後の更新は[月替わりテーマ](../monthly-wafu-themes.md)に記録しています。Pi上の画面取得と物理パネルの確認は区別しています。

設定範囲は[対応表](SETTINGS_STATUS.md)、今回の監査結果は[文書監査](../documentation-audit-2026-10-01.md)を参照してください。
