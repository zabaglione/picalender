# 月替わりの和風テーマ

和風月名から連想する情景を、12枚の手描き・和紙調の背景として表現します。共通の紙の質感、余白、文字の読みやすさを保ち、草木や情景で月ごとの違いを出します。月名は旧暦由来で、現在の季節とはずれがあります。由来にも諸説があるため、[国立国会図書館「和風月名」](https://www.ndl.go.jp/koyomi/chapter3/s8.html)の代表的な説明を意匠の出発点にしています。切替は設定タイムゾーンの**新暦の月**に従います。

| 月 | 和風月名 | 意匠の連想 |
| --- | --- | --- |
| 1月 | 睦月 | 集いと結び。松、祝いの扇、朱の結び紐 |
| 2月 | 如月 | 重ねた衣。折り重ねた布、菱模様、梅の枝 |
| 3月 | 弥生 | 草木の生長。芽、伸びる茎、葉の曲線 |
| 4月 | 卯月 | 卯の花。白い五弁花、細い枝、淡い緑 |
| 5月 | 皐月 | 早苗。山あいの水田、並ぶ稲の芽 |
| 6月 | 水無月 | 田へ引く水。草木に囲まれた水の流れ |
| 7月 | 文月 | 実る稲穂。垂れた穂、金色の粒 |
| 8月 | 葉月 | 葉が落ちる情景。風に舞う葉、赤銅と黄土 |
| 9月 | 長月 | 長い夜。藍の空、星、すすき |
| 10月 | 神無月 | 神域。杉と紅葉に囲まれた朱の鳥居 |
| 11月 | 霜月 | 霜。凍った枝や草、銀青の色合い |
| 12月 | 師走 | 年の瀬。冬の松、暖かい灯り、鐘 |

時刻、日付、暦、祝日、六曜、天文情報、天気、出典表記の内容と座標は維持します。日替わり画像は色加工せずに表示し、月替わり時にキャッシュファイルがなくても直前の正常な画像を保持します。装飾は月齢の計算結果を表すものではなく、長月の背景には月の図案を加えません。

背景は2026-10-01に組み込みimage_genで制作し、`assets/field_notes/monthly/` に保存しています。制作時のプロンプトは同ディレクトリの `generation-prompts.json` にあります。実行時には保存済みPNGを使い、起動時と月替わり時だけ読み込みます。外部の画像生成やネットワーク接続は不要です。背景の欠損・破損時は無地の紙色を使って情報表示を継続します。

時計・暦・天気の背後には共通の薄い紙面を重ねます。幾何模様や月別の複雑な枠を廃し、日付の選択表示も共通の形に揃えています。
