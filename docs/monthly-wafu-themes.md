# 月替わりの和風テーマ

和風月名から連想する情景を、背景、枠、模様、ヘッダーの小さな図案へ展開します。月名は旧暦由来で、現在の季節とはずれがあります。由来にも諸説があるため、[国立国会図書館「和風月名」](https://www.ndl.go.jp/koyomi/chapter3/s8.html)の代表的な説明を意匠の出発点にしています。切替は設定タイムゾーンの**新暦の月**に従います。

| 月 | 和風月名 | 意匠の連想 |
| --- | --- | --- |
| 1月 | 睦月 | 集いと結び。祝いの結び紐、松、朱と金 |
| 2月 | 如月 | 重ねた衣。布地の層、菱模様、襟と裾 |
| 3月 | 弥生 | 草木の生長。芽、伸びる茎、葉の曲線 |
| 4月 | 卯月 | 卯の花。白い五弁花、細い枝、淡い緑 |
| 5月 | 皐月 | 早苗。田の区画、水田に並ぶ稲の芽 |
| 6月 | 水無月 | 田へ引く水。水路、波紋、流れる線 |
| 7月 | 文月 | 実る稲穂。垂れた穂、金色の粒、織り目 |
| 8月 | 葉月 | 葉が落ちる情景。風に舞う葉、赤銅と黄土 |
| 9月 | 長月 | 長い夜。藍の空、星、すすき |
| 10月 | 神無月 | 神域。鳥居、紙垂、杉、朱の枠 |
| 11月 | 霜月 | 霜。氷晶、凍った枝、銀青の線 |
| 12月 | 師走 | 年の瀬。走るような曲線、灯り、鐘、墨と金 |

時刻、日付、暦、祝日、六曜、天文情報、天気、出典表記の内容と座標は維持します。日替わり画像は色加工せずに表示し、月替わり時にキャッシュファイルがなくても直前の正常な画像を保持します。装飾は月齢の計算結果を表すものではなく、長月の背景には月の図案を加えません。

図案はPygameで描き、静的な背景として月替わり時にキャッシュします。描画は決定的で、外部の画像生成やネットワーク接続を必要としません。

## ローカルの描画確認

12か月の原寸PNGと一覧を出力します。天気は既存のキャッシュを使用します。

```sh
venv/bin/python scripts/render_preview.py --offline --all-months \
  --at 2026-09-15T12:34:56+09:00 \
  --output output/wafu-themes/preview.png

SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy venv/bin/python -m pytest -q \
  tests/test_monthly_theme.py tests/test_daily_art.py
```

原寸画像は `preview-01.png` から `preview-12.png`、一覧は `preview.png` です。プレビューの見出しだけに和風月名を付け、実画面の表示項目は増やしていません。

## 内容保持の確認（2026-09-30）

変更前後で同じ日時・天気データを与え、12か月・1,126回の文字描画について、文言、座標、文字サイズ、フォント、中央揃えの指定がすべて一致しました。秒表示の書式・座標計算、カレンダー・六曜・天文・天気の取得と計算処理も維持しています。

月境界・年越し・正常な画像の保持・同じ配色でも12種類の図案が異なること・再描画の決定性を含む対象テストは29件通過しました。12か月の原寸PNGをすべて目視確認しました。実際の背景上で2画素おきに文字の主要画素をサンプリングした範囲では、最小コントラストは4.56:1でした。フォントのアンチエイリアスの全画素や実機パネルの特性を測定した値ではありません。

Astraによるソースと一覧画像のレビューでは、完了を妨げる指摘はありませんでした。如月の模様の呼称は実装に合わせて「菱模様」としました。

## Raspberry Piへの反映（2026-09-30）

Pi上の候補ディレクトリで対象テスト29件が通過し、12か月の描画を確認しました。既存の作業状態を保持するため、バックアップ付き更新スクリプトで描画用の2ファイルだけを反映しました。反映後のSHA-256は候補ファイルと一致し、設定ファイルと日替わり画像のSHA-256も更新前と一致しました。

反映後のサービスは `active/running`、再起動回数は0でした。稼働中のPygame画面を9月30日08:54 JSTに取得し、長月の意匠、表示内容、既存の日替わり画像を確認しました。稼働プロセスのエラーログはありませんでした。起動時の別プロセスにはWaylandへの接続を試みたエラーログがありましたが、KMSDRMで稼働する本体プロセスには発生していません。

この確認はPi上の稼働画面のキャプチャによるものです。実物の液晶パネルをカメラで撮影して確認したものではありません。設定、キャッシュ、取得画像はリポジトリへ追加していません。
