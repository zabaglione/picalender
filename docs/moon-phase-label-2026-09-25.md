# 月相名の表示条件（2026-09-25）

2026年9月25日の画面に `Full moon` と出た原因は、旧実装が月相角180度の前後22.5度をまとめて満月と呼んでいたため。25日正午の角度は約160.6度、照明率は約97.2%で、満月の瞬間には達していない。

[国立天文台の2026年暦要項](https://eco.mtk.nao.ac.jp/koyomi/yoko/2026/rekiyou263.html)は9月の望を日本時間27日1:49と公表している。[米海軍天文台の月相表](https://aa.usno.navy.mil/calculated/moon/phases?date=2026-09-01&nump=8)も26日16:49 UTC（日本時間27日1:49）と一致する。[こよみのページ](https://koyomi8.com/moonage.html)は日々の月齢を正午の値として示し、望の日時を別に示す。

画面の月相名は日本時間の日付単位とする。新月・上弦・満月・下弦は、それぞれの天文現象が起こる当日にだけ表示し、その間は月相角に応じて満ちていく月／欠けていく月の名称を表示する。月齢は直前の新月からの経過日数、照明率は見かけの明るい面の割合として、時刻に応じて連続的に計算する。月相名は英語と日本語を併記する。

この規則では9月25日・26日は `Waxing gibbous / 満ちていく月`、27日は `Full moon / 満月`、28日は `Waning gibbous / 欠けていく月` となる。満月は厳密には27日1:49の瞬間であり、「満月」の日付表示はその日の呼称である。

## 検証と実機反映

- ローカルの関連テスト134件が成功。2026年の朔弦望50件と国立天文台の公表時刻の照合も含む。
- 9月25日と27日のローカルプレビュー、およびPi上の検証用コピーの25日プレビューで、月相名・日本語・枠内の配置を画像確認。
