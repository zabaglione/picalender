# 2026-09-18 デザイン・月齢・六曜の更新記録

時計、月、カレンダー、天気を1024 × 600の画面に再配置した。
紙色と深い緑の配色、ゆがみを少し加えた輪郭、描き下ろしの森とキツネのイラスト、
Fraunces / DM Sans / Zen Maru Gothicを使用する。六曜は日付の下に日本語で表示し、
祝日は色・印と直近の祝日名で示す。描画面をキャッシュし、時計は秒単位、月は分単位で更新する。

画像は組み込み image_gen で生成し、`assets/field_notes/forest-fox.png` に保存。
最終プロンプトとフォントの出典・ライセンスは同ディレクトリの `README.md` に記録した。

## 月の修正

旧版では2000年の基準新月から平均朔望月で割った余りを使っていた。
UTCと日本時間の区別もなく、実時間ではなくその日の固定時刻で計算していた。
図形も月齢を直線的に形へ変換しており、照明率と合わず、欠けていく側の向きも誤っていた。

新版は [Astronomy Engine](https://github.com/cosinekitty/astronomy/tree/master/source/python) を用いて、
直前の実際の新月からの経過日数を月齢とする。日付だけを渡すAPIは日本時間の正午、
タイムゾーンのない日時は日本時間、タイムゾーン付き日時はその瞬間として扱う。
画面は現在時刻を渡す。演算はオフラインで完結する。

月相の8分類は太陽と月の黄経差による近似的な名称。朔・弦・望の正確なイベント時刻は別に検索する。
月の図形は計算された照明率を使い、球面の明暗境界を描く。
満ちる月は右、欠ける月は左が明るい北を上にした模式図で、地平線に対する傾きや月出没は表していない。

[国立天文台の2026年暦要項](https://eco.mtk.nao.ac.jp/koyomi/yoko/2026/rekiyou263.html)
の50件（朔・上弦・望・下弦）を独立した参照値として使用。
公表時刻は分単位で、照合結果の最大差は **67.341803秒**。
この差は2026年の検証結果であり、すべての年代での精度保証ではない。
月齢7.3・照明約46%となる2026-09-18夜の実機画面でも、半月に近い図形を確認した。

## 六曜の修正

旧版は1900年からの日数を6で割るだけで、旧暦月初の切り替えがなかった。
新版は日本時間の新月日と中気から旧暦の月・日を求め、そこから六曜を決める。
月齢が新月の瞬間に0になるのに対し、旧暦の1日は新月を含む日の0時から始まる。

2033年の旧暦は一意に定まらないため、冬至を優先する閏11月案を採用した。
[国立天文台の説明](https://eco.mtk.nao.ac.jp/koyomi/topics/html/topics2014.html)
にある1984–1985年、2014年、2033–2034年の月境界と照合。
2025年の閏6月、2026年の月初・六曜の切り替えも確認した。
